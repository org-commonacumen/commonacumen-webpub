    Processing RTX Spark GB10 Demand with Excel and Copilot Cowork with a GitHub Repo and Demo

    Not sure if you saw this week’s Surface Ultra launch on October 7, 2026. I put together a GitHub repo demonstrating demand planning and processing spreadsheets with synthetic data using Cowork. I used to do this for IBM in the 1990s for IBM servers, desktops, and laptops for the Large Accounts, Demand Planning, and Cost Engineering teams at IBM PC Company. Except it was with PROFS email, Lotus 1-2-3 spreadsheets, DB2, and a decision support product called Metaphor. Kind of retro, modern, and frontier all at the same time.

    You can find the demo here: Cowork Demo of Processing RTX Spark GB10 Demand with Excel and Copilot Cowork

    Data Appended into the Summary spreadsheet

    Here is an image of the summary spreadsheet created using a prompt in Copilot Cowork:

    You can find the prompt in the README here: Part 2 — Cowork: aggregate spreadsheets from a OneDrive folder

    In my OneDrive folder "C:\Users\<you>\OneDrive - Microsoft\SurfaceCatalogs", find every .xlsx
file (skip any file whose name starts with "summary", and ignore the output subfolder). Append
the attached spreadsheets into a single summary<dateRun>.xlsx, where <dateRun> is the 
current date and time (for example 2026-10-01_1408) so running it more than once a day won't 
overwrite the previous file. Keep one header row, add a "Source File" column so I can tell which
retailer each row came from, and drop any blank or total rows. Confirm the columns match across 
all three files first, then show me the row count and which files were combined. Fix any column
order discrepancies, as well as converting any units (like grams, oz, pounds to one unit of measure)
with a preference for pounds related to weight and inches related to things like screen size. Save
it inside a "PromptSummary" subfolder of that OneDrive folder (create the PromptSummary folder
if it doesn't exist). Do not modify the source files. When done, tell me the row count, the column
count, and which files were combined.

    Have a look and try to set up the demo in your Copilot Cowork.
